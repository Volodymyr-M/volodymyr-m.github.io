Welche Projektdateien lassen sich im Browser öffnen? Die vollständige Liste

Die meisten Menschen kommen mit einer Datei zu Ingantt. Manchmal ist es eine .mpp aus Microsoft Project. Oft genug ist es eine .xer aus Primavera P6, eine .gan aus GanttProject oder etwas, das ein Auftragnehmer geschickt hat und das im Team niemand mehr öffnen kann.

Hier also die schlichte Liste, ohne Marketing darum herum.

Was Ingantt für Web öffnet

Ingantt für Web öffnet mehr als 12 Formate; maßgeblich ist der Artikel zu Import und Export im Hilfebereich. Die Kurzfassung:

  • Microsoft Project — MPP, MPT, MPX, XML
  • Oracle Primavera P6 — XER, PMXML
  • GanttProject — GAN
  • ProjectLibre — POD
  • Asta Powerproject — PP
  • ConceptDraw — CDPX
  • FastTrack Schedule — FTS
  • GNOME Planner
  • Phoenix Project Manager — PPX
  • Synchro — SP
  • TurboProject — PEP
  • SDEF sowie Ingantts eigenes YAML

Sie brauchen keine Lizenz für das Werkzeug, aus dem die Datei stammt. Sie brauchen dieses Werkzeug auch nicht installiert. Die Datei öffnet sich als vollständiges interaktives Gantt-Diagramm — Teilvorgänge, Abhängigkeiten, Ressourcenzuordnungen, Meilensteine, Basispläne und der kritische Pfad — und ist von dort aus bearbeitbar, nicht nur lesbar.

Was zurückgeschrieben wird

Das ist die Hälfte der Frage, die darüber entscheidet, ob Sie das Ganze wirklich nutzen können.

Ingantt speichert in MS Project-kompatiblem XML, sodass ein hier geöffneter Plan zurück an Kolleginnen und Kollegen gehen kann, die weiterhin mit Project arbeiten. Über das Menü „Datei“ — im Web Download — exportieren Sie außerdem nach PDF, PNG, CSV, XML, YAML und Markdown.

Das ist wichtig für die unbequeme Zwischenphase einer Migration, in der die eine Hälfte des Teams gewechselt hat und die andere noch nicht. Sie verlangen von niemandem, am selben Tag umzusteigen.

Die eine Formatfrage, die man zuerst stellen sollte

.mpp ist ein proprietäres Binärformat. Jedes Werkzeug, das es liest, hat Microsofts Format rückentwickelt — Ingantt eingeschlossen — und bei komplizierten Plänen zeigen sich die Unterschiede. Öffnen Sie Ihre echte Datei, nicht ein Beispiel, und prüfen Sie die vier Dinge, die für Sie tatsächlich zählen: die Verknüpfungen der Abhängigkeiten, die Ressourcenzuordnungen, die Kalender und das Endedatum. Kommen die an, ist der Rest Detail.

Wenn Ihre Datei konkret eine .mpp ist, finden Sie eine Schritt-für-Schritt-Anleitung zum Öffnen einer .MPP-Datei. Und wenn Sie zu den Teams gehören, deren Pläne mit Project Online verschwunden sind, ist diese Seite der nützlichere Ausgangspunkt.
