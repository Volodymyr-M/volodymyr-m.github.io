Quali file di progetto si possono aprire nel browser? L'elenco completo

Quasi tutti arrivano a Ingantt con un file in mano. A volte è un .mpp di Microsoft Project. Spesso è un .xer di Primavera P6, un .gan di GanttProject, o qualcosa che ha mandato un fornitore e che in squadra nessuno ha più il software per aprire.

Ecco quindi l'elenco, senza marketing intorno.

Cosa apre Ingantt per il Web

Ingantt per il Web apre più di 12 formati, e l'articolo su importazione ed esportazione del centro assistenza è l'elenco di riferimento. In breve:

  • Microsoft Project — MPP, MPT, MPX, XML
  • Oracle Primavera P6 — XER, PMXML
  • GanttProject — GAN
  • ProjectLibre — POD
  • Asta Powerproject — PP
  • ConceptDraw — CDPX
  • FastTrack Schedule — FTS
  • GNOME Planner
  • Phoenix Project Manager — PPX
  • Synchro — SP
  • TurboProject — PEP
  • SDEF e lo YAML nativo di Ingantt

Non serve una licenza dello strumento da cui arriva il file. Non serve nemmeno averlo installato. Il file si apre come diagramma di Gantt interattivo completo — attività secondarie, dipendenze, assegnazioni di risorse, milestone, previsioni di riferimento e percorso critico — e da lì è modificabile, non solo leggibile.

Cosa restituisce

Questa è la metà della domanda che decide se lo strumento vi è davvero utile.

Ingantt salva in XML compatibile con MS Project, così un piano aperto qui può tornare a un collega che usa ancora Project. Dal menu File — Scarica sul Web — si esporta anche in PDF, PNG, CSV, XML, YAML e Markdown.

Conta nel periodo scomodo di una migrazione, quando metà della squadra si è spostata e metà no. Non state chiedendo a nessuno di cambiare lo stesso giorno.

L'unica domanda sui formati da farsi per prima

.mpp è un binario proprietario. Ogni strumento che lo legge sta facendo reverse engineering del formato Microsoft, Ingantt compreso, ed è nei piani complicati che le differenze si vedono. Aprite il vostro file vero — non un esempio — e controllate le quattro cose che vi interessano davvero: i collegamenti di dipendenza, le assegnazioni di risorse, i calendari e la data di fine. Se quelle arrivano, il resto è dettaglio.

Se il file è proprio un .mpp, c'è una guida passo per passo per aprire un file .MPP. E se siete tra le squadre i cui piani sono andati via con Project Online, quella pagina è il punto di partenza più utile.
