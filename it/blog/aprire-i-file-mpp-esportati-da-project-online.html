Come aprire i file .MPP esportati da Project Online senza Microsoft Project

La data di dismissione di Project Online fissata da Microsoft è il 30 settembre 2026. Dopo di essa i progetti conservati nel servizio non sono più raggiungibili, e non è previsto alcun periodo in sola lettura: ciò che è stato esportato prima è la copia di riferimento.

Se i vostri progetti sono stati salvati tramite Project desktop, quello che avete adesso è una cartella di file .MPP. Da cui la domanda che di solito arriva qualche giorno dopo: che cosa li apre? Il .MPP è il formato binario proprietario di Microsoft Project, e in molti team le licenze Project se ne sono andate più o meno insieme al servizio.

Ingantt li apre nel browser. Caricate il file o sceglietelo da Google Drive, e il progetto torna come diagramma di Gantt interattivo completo: sotto-attività, dipendenze, assegnazioni di risorse, milestone, baseline e percorso critico. Il MS Project XML che sta accanto ai vostri export si apre allo stesso modo. Nessuna licenza, niente da installare, e funziona allo stesso modo su macOS, Linux o un Chromebook. Aprire un file .MPP richiede una trentina di secondi.

Non è nemmeno un visualizzatore: un piano esportato può essere ripianificato ed esportato di nuovo in MS Project XML per i colleghi rimasti su Project.

Vale la pena essere chiari sui limiti: Project Online era una piattaforma PPM aziendale, e Ingantt non sostituisce l'analisi di portfolio, i workflow di stage gate, i timesheet o la reportistica OData. Ciò che sostituisce è la metà di pianificazione, cioè i piani stessi. Se è quella la parte che vi serve funzionante il 1º ottobre, trovate più dettagli nella pagina sull'alternativa a Project Online.
