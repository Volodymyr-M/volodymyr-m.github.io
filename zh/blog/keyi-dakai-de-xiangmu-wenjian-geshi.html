浏览器里能打开哪些项目文件？完整清单

大多数人来找 Ingantt 时，手里已经有一个文件。有时是 Microsoft Project 的 .mpp。相当多的时候是 Primavera P6 的 .xer、GanttProject 的 .gan，或者是承包商发来的、团队里已经没人装得起相应软件去打开的东西。

所以这里直接给清单，不加任何包装。

Ingantt for Web 能打开什么

Ingantt for Web 可以打开 12 种以上的格式，帮助中心的导入与导出文章是权威清单。简要版本：

  • Microsoft Project — MPP、MPT、MPX、XML
  • Oracle Primavera P6 — XER、PMXML
  • GanttProject — GAN
  • ProjectLibre — POD
  • Asta Powerproject — PP
  • ConceptDraw — CDPX
  • FastTrack Schedule — FTS
  • GNOME Planner
  • Phoenix Project Manager — PPX
  • Synchro — SP
  • TurboProject — PEP
  • SDEF，以及 Ingantt 自己的 YAML

你不需要文件来源工具的授权，也不需要安装那个工具。文件会以一张完整的交互式甘特图打开——子任务、依赖关系、资源分配、里程碑、基准和关键路径都在——而且从那一刻起它是可编辑的，不只是可阅读。

它能写回什么

这是决定你能不能真正用起来的另一半问题。

Ingantt 以 兼容 MS Project 的 XML 保存，所以在这里打开的计划可以回到仍在用 Project 的同事手上。在“文件”菜单中——网页端是 下载 ——还可以导出为 PDF、PNG、CSV、XML、YAML 和 Markdown。

这在迁移中那段别扭的过渡期很重要：一半团队已经搬过来，另一半还没有。你不必要求任何人在同一天切换。

关于格式，值得先问的一个问题

.mpp 是专有二进制格式。所有能读它的工具都是在对微软的格式做逆向工程，Ingantt 也一样，而差异往往出现在复杂的计划上。请打开你真正的文件，不要用示例，然后检查对你真正重要的四件事：依赖链接、资源分配、日历和完成日期。这四样过来了，其余就是细节。

如果你的文件恰好是 .mpp，有一份逐步说明讲如何打开 .MPP 文件。如果你属于计划随 Project Online 一起消失的那类团队，那个页面是更合适的起点。
