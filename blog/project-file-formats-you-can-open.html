Which project files can you open in a browser? The full list

Most people arrive at Ingantt holding a file. Sometimes it is an .mpp from Microsoft Project. Often enough it is an .xer from Primavera P6, a .gan from GanttProject, or something a contractor sent over that nobody on the team has the software to open any more.

So here is the plain list, with no marketing around it.

What Ingantt for Web opens

Ingantt for Web opens 12+ formats, and the help centre's import and export article is the authoritative list. The short version:

  • Microsoft Project — MPP, MPT, MPX, XML
  • Oracle Primavera P6 — XER, PMXML
  • GanttProject — GAN
  • ProjectLibre — POD
  • Asta Powerproject — PP
  • ConceptDraw — CDPX
  • FastTrack Schedule — FTS
  • GNOME Planner
  • Phoenix Project Manager — PPX
  • Synchro — SP
  • TurboProject — PEP
  • SDEF, and Ingantt's own YAML

You do not need a licence for the tool the file came from. You do not need that tool installed. The file opens as a full interactive Gantt chart — sub-tasks, dependencies, resource assignments, milestones, baselines and the critical path — and from there it is editable, not just readable.

What it writes back

This is the half of the question that decides whether you can actually use the thing.

Ingantt saves in MS Project-compatible XML, so a plan you open here can go back to a colleague still running Project. From the File menu — Download on the web — you can also export to PDF, PNG, CSV, XML, YAML and Markdown.

That matters for the awkward middle period of a migration, where half the team has moved and half has not. You are not asking anyone to switch on the same day.

The one format question worth asking first

.mpp is a proprietary binary. Every tool that reads it is reverse-engineering Microsoft's format, Ingantt included, and complicated plans are where the differences show up. Open your real file — not a sample — and check the four things that actually matter to you: the dependency links, the resource assignments, the calendars, and the finish date. If those come across, the rest is detail.

If your file is an .mpp specifically, there is a step-by-step walkthrough on opening a .MPP file. If you are one of the teams whose plans left with Project Online, that page is the more useful starting point.
