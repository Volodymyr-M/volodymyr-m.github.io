Que ficheiros de projeto se podem abrir no navegador? A lista completa

A maioria das pessoas chega ao Ingantt com um ficheiro na mão. Às vezes é um .mpp do Microsoft Project. Com frequência é um .xer do Primavera P6, um .gan do GanttProject, ou algo que um fornecedor enviou e que já ninguém na equipa tem software para abrir.

Aqui fica a lista, sem marketing à volta.

O que o Ingantt para Web abre

O Ingantt para Web abre mais de 12 formatos, e o artigo sobre importação e exportação do centro de ajuda é a lista de referência. A versão curta:

  • Microsoft Project — MPP, MPT, MPX, XML
  • Oracle Primavera P6 — XER, PMXML
  • GanttProject — GAN
  • ProjectLibre — POD
  • Asta Powerproject — PP
  • ConceptDraw — CDPX
  • FastTrack Schedule — FTS
  • GNOME Planner
  • Phoenix Project Manager — PPX
  • Synchro — SP
  • TurboProject — PEP
  • SDEF e o YAML próprio do Ingantt

Não precisa de uma licença da ferramenta de onde veio o ficheiro. Nem precisa de a ter instalada. O ficheiro abre como um diagrama de Gantt interativo completo — subtarefas, dependências, atribuições de recursos, marcos, linhas de base e o caminho crítico — e a partir daí é editável, não apenas legível.

O que devolve

Esta é a metade da pergunta que decide se consegue mesmo usar a ferramenta.

O Ingantt grava em XML compatível com o MS Project, pelo que um plano aberto aqui pode voltar para um colega que continue no Project. No menu Ficheiro — Descarregar na web — também pode exportar para PDF, PNG, CSV, XML, YAML e Markdown.

Isso conta no período incómodo de uma migração, quando metade da equipa já mudou e a outra metade não. Não está a pedir a ninguém que mude no mesmo dia.

A pergunta sobre formatos que vale a pena fazer primeiro

.mpp é um binário proprietário. Todas as ferramentas que o leem estão a fazer engenharia inversa ao formato da Microsoft, o Ingantt incluído, e é nos planos complicados que as diferenças aparecem. Abra o seu ficheiro real — não uma amostra — e verifique as quatro coisas que de facto lhe importam: as ligações de dependência, as atribuições de recursos, os calendários e a data de conclusão. Se isso passar, o resto é detalhe.

Se o seu ficheiro for concretamente um .mpp, existe um guia passo a passo para abrir um ficheiro .MPP. E se faz parte das equipas cujos planos saíram com o Project Online, essa página é o melhor ponto de partida.
