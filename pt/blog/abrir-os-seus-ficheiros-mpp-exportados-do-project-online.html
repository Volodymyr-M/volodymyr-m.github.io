Como abrir os ficheiros .MPP exportados do Project Online sem o Microsoft Project

A data de desativação do Project Online definida pela Microsoft é 30 de setembro de 2026. A partir daí, os projetos guardados no serviço deixam de estar acessíveis, e não há período de apenas leitura — o que foi exportado antes é a cópia de referência.

Se os seus projetos foram guardados através do Project para computador, o que tem agora é uma pasta de ficheiros .MPP. O que levanta a pergunta que costuma chegar alguns dias depois: o que é que os abre? O .MPP é o binário proprietário do Microsoft Project, e em muitas equipas as licenças do Project foram-se mais ou menos ao mesmo tempo que o serviço.

O Ingantt abre-os no navegador. Carregue o ficheiro ou escolha-o a partir do Google Drive, e o projeto volta como um gráfico de Gantt interativo completo — subtarefas, dependências, atribuições de recursos, marcos, linhas de base e o caminho crítico. O MS Project XML que está ao lado dos seus exports abre da mesma maneira. Sem licença, sem nada para instalar, e funciona igual em macOS, Linux ou num Chromebook. Abrir um ficheiro .MPP demora cerca de trinta segundos.

Também não é um visualizador — um plano exportado pode ser replaneado e exportado de volta para MS Project XML para colegas que continuam no Project.

Vale a pena ser direto quanto aos limites: o Project Online era uma plataforma PPM empresarial, e o Ingantt não substitui a análise de portefólio, os fluxos de pontos de decisão, as folhas de horas nem os relatórios OData. O que substitui é a metade de agendamento — os próprios planos. Se for essa a parte que precisa a funcionar a 1 de outubro, há mais detalhe na página sobre a alternativa ao Project Online.
