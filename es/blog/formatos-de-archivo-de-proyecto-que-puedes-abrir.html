¿Qué archivos de proyecto se pueden abrir en el navegador? La lista completa

Casi todo el mundo llega a Ingantt con un archivo en la mano. A veces es un .mpp de Microsoft Project. Con bastante frecuencia es un .xer de Primavera P6, un .gan de GanttProject, o algo que envió un contratista y que ya nadie del equipo tiene software para abrir.

Así que aquí está la lista, sin marketing alrededor.

Lo que abre Ingantt para Web

Ingantt para Web abre más de 12 formatos, y el artículo sobre importación y exportación del centro de ayuda es la lista autorizada. La versión corta:

  • Microsoft Project — MPP, MPT, MPX, XML
  • Oracle Primavera P6 — XER, PMXML
  • GanttProject — GAN
  • ProjectLibre — POD
  • Asta Powerproject — PP
  • ConceptDraw — CDPX
  • FastTrack Schedule — FTS
  • GNOME Planner
  • Phoenix Project Manager — PPX
  • Synchro — SP
  • TurboProject — PEP
  • SDEF y el YAML propio de Ingantt

No necesitas una licencia de la herramienta de la que salió el archivo. Tampoco necesitas tenerla instalada. El archivo se abre como un diagrama de Gantt interactivo completo — subtareas, dependencias, asignaciones de recursos, hitos, líneas base y la ruta crítica — y a partir de ahí es editable, no solo legible.

Lo que devuelve al guardar

Esta es la mitad de la pregunta que decide si de verdad puedes usar la herramienta.

Ingantt guarda en XML compatible con MS Project, así que un plan que abras aquí puede volver a un colega que siga usando Project. Desde el menú Archivo — Descargar en la web — también puedes exportar a PDF, PNG, CSV, XML, YAML y Markdown.

Eso importa en el periodo incómodo de una migración, cuando media parte del equipo ya se ha movido y la otra no. No le estás pidiendo a nadie que cambie el mismo día.

La pregunta sobre formatos que conviene hacerse primero

.mpp es un binario propietario. Toda herramienta que lo lee está aplicando ingeniería inversa al formato de Microsoft, Ingantt incluido, y es en los planes complicados donde aparecen las diferencias. Abre tu archivo real — no una muestra — y comprueba las cuatro cosas que de verdad te importan: los vínculos de dependencia, las asignaciones de recursos, los calendarios y la fecha de fin. Si eso llega bien, el resto es detalle.

Si tu archivo es concretamente un .mpp, hay una guía paso a paso para abrir un archivo .MPP. Y si formas parte de los equipos cuyos planes se fueron con Project Online, esa página es el mejor punto de partida.
