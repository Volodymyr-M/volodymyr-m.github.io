2026年9月26日

ブラウザーで開けるプロジェクトファイルは何か — 全リスト

Ingantt にたどり着く方のほとんどは、手元にファイルを持っています。Microsoft Project の .mpp のこともあります。Primavera P6 の .xer、GanttProject の .gan、あるいは協力会社から送られてきて、もう社内の誰も開くソフトを持っていないファイルであることも少なくありません。

ですので、余計な宣伝なしでそのまま一覧を並べます。

Ingantt for Web が開く形式

Ingantt for Web は 12 以上の形式 を開きます。正式な一覧はヘルプセンターのインポートとエクスポートの記事です。要点だけ挙げると:

  • Microsoft Project — MPP、MPT、MPX、XML
  • Oracle Primavera P6 — XER、PMXML
  • GanttProject — GAN
  • ProjectLibre — POD
  • Asta Powerproject — PP
  • ConceptDraw — CDPX
  • FastTrack Schedule — FTS
  • GNOME Planner
  • Phoenix Project Manager — PPX
  • Synchro — SP
  • TurboProject — PEP
  • SDEF、および Ingantt 独自の YAML

そのファイルを作ったツールのライセンスは要りません。そのツールをインストールしておく必要もありません。ファイルは完全な対話型のガントチャートとして開きます。サブタスク、依存関係、リソースの割り当て、マイルストーン、ベースライン、クリティカルパスまで揃った状態で、そこから閲覧だけでなく編集もできます。

書き戻せる形式

実際に使えるかどうかを決めるのは、じつはこちら半分の問いです。

Ingantt は MS Project 互換の XML で保存します。ここで開いた計画を、まだ Project を使っている同僚に戻せるということです。ファイルメニュー（ウェブでは ダウンロード）からは PDF、PNG、CSV、XML、YAML、Markdown へのエクスポートもできます。

これが効くのは、移行の途中にある気まずい時期です。チームの半分は移り、半分はまだ移っていない。誰にも同じ日に乗り換えろとは言わずに済みます。

最初に確かめておきたい形式の話

.mpp は独自仕様のバイナリです。これを読めるツールはどれも Microsoft の形式をリバースエンジニアリングしており、Ingantt も同じです。そして違いが表に出るのは複雑な計画のときです。サンプルではなく実物のファイルを開いて、本当に大事な四つ、依存関係のリンク、リソースの割り当て、カレンダー、終了日を確かめてください。そこが通れば、あとは細部です。

ファイルがまさに .mpp なら、.MPP ファイルを開く手順を順に追った記事があります。計画が Project Online と一緒に消えてしまったチームであれば、そのページのほうが出発点として役立ちます。
