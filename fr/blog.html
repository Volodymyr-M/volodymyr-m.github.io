Quels fichiers de projet peut-on ouvrir dans un navigateur ? La liste complète

La plupart des gens arrivent chez Ingantt avec un fichier. Parfois un .mpp de Microsoft Project. Assez souvent un .xer de Primavera P6, un .gan de GanttProject, ou quelque chose qu'un prestataire a envoyé et que plus personne dans l'équipe n'a le logiciel pour ouvrir.

Voici donc la liste, sans marketing autour.

Ce qu'Ingantt pour le Web ouvre

Ingantt pour le Web ouvre plus de 12 formats, et l'article sur l'import et l'export du centre d'aide fait référence. La version courte :

  • Microsoft Project — MPP, MPT, MPX, XML
  • Oracle Primavera P6 — XER, PMXML
  • GanttProject — GAN
  • ProjectLibre — POD
  • Asta Powerproject — PP
  • ConceptDraw — CDPX
  • FastTrack Schedule — FTS
  • GNOME Planner
  • Phoenix Project Manager — PPX
  • Synchro — SP
  • TurboProject — PEP
  • SDEF, et le YAML propre à Ingantt

Vous n'avez pas besoin d'une licence de l'outil dont vient le fichier. Vous n'avez pas besoin que cet outil soit installé. Le fichier s'ouvre comme un diagramme de Gantt interactif complet — sous-tâches, dépendances, affectations de ressources, jalons, planifications initiales et chemin critique — et il est ensuite modifiable, pas seulement consultable.

Ce qu'il réécrit

C'est la moitié de la question qui décide si vous pouvez réellement vous en servir.

Ingantt enregistre en XML compatible MS Project, de sorte qu'un plan ouvert ici peut repartir vers un collègue resté sur Project. Depuis le menu Fichier — Télécharger sur le Web — vous pouvez aussi exporter en PDF, PNG, CSV, XML, YAML et Markdown.

Cela compte pendant la période inconfortable d'une migration, quand la moitié de l'équipe a basculé et l'autre pas. Vous ne demandez à personne de changer le même jour.

La seule question de format à se poser d'abord

.mpp est un binaire propriétaire. Tout outil qui le lit fait de l'ingénierie inverse sur le format de Microsoft, Ingantt compris, et c'est dans les plans compliqués que les différences se voient. Ouvrez votre vrai fichier — pas un exemple — et vérifiez les quatre choses qui comptent vraiment pour vous : les liens de dépendance, les affectations de ressources, les calendriers et la date de fin. Si cela passe, le reste est du détail.

Si votre fichier est précisément un .mpp, il existe un guide pas à pas pour ouvrir un fichier .MPP. Et si vous faites partie des équipes dont les plans sont partis avec Project Online, cette page est le meilleur point de départ.
