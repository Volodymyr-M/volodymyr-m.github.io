Comment ouvrir vos fichiers .MPP exportés de Project Online sans Microsoft Project

La date d'arrêt de Project Online fixée par Microsoft est le 30 septembre 2026. Passé ce jour, les projets stockés dans le service ne sont plus accessibles, et il n'y a pas de période en lecture seule — ce qui a été exporté avant constitue la copie de référence.

Si vos projets ont été enregistrés via Project bureau, vous vous retrouvez aujourd'hui avec un dossier de fichiers .MPP. D'où la question qui arrive en général quelques jours plus tard : qu'est-ce qui les ouvre ? Le .MPP est le format binaire propriétaire de Microsoft Project, et dans beaucoup d'équipes les licences Project sont parties à peu près en même temps que le service.

Ingantt les ouvre dans le navigateur. Téléversez le fichier ou sélectionnez-le depuis Google Drive, et le projet revient sous forme de diagramme de Gantt interactif complet — sous-tâches, dépendances, affectations de ressources, jalons, planifications de référence et chemin critique. Le MS Project XML posé à côté de vos exports s'ouvre de la même manière. Aucune licence, rien à installer, et cela fonctionne pareil sur macOS, Linux ou un Chromebook. Ouvrir un fichier .MPP prend une trentaine de secondes.

Ce n'est pas non plus une simple visionneuse — un plan exporté peut être replanifié, puis réexporté en MS Project XML pour les collègues restés sur Project.

Autant être clair sur les limites : Project Online était une plateforme PPM d'entreprise, et Ingantt ne remplace ni l'analyse de portefeuille, ni les workflows de jalons d'approbation, ni les feuilles de temps, ni le reporting OData. Ce qu'il remplace, c'est la moitié planification — les plans eux-mêmes. Si c'est cette partie qui doit fonctionner le 1er octobre, la page sur l'alternative à Project Online entre dans le détail.
