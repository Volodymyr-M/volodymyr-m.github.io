ไฟล์โครงการแบบไหนที่เปิดได้ในเบราว์เซอร์? รายการทั้งหมด

คนส่วนใหญ่มาถึง Ingantt พร้อมไฟล์ในมือ บางครั้งเป็น .mpp จาก Microsoft Project บ่อยครั้งเป็น .xer จาก Primavera P6, .gan จาก GanttProject หรือไฟล์ที่ผู้รับเหมาส่งมาแล้วไม่มีใครในทีมมีซอฟต์แวร์เปิดได้อีกต่อไป

ฉะนั้นนี่คือรายการตรง ๆ โดยไม่มีคำโฆษณาห่อไว้

Ingantt for Web เปิดอะไรได้

Ingantt for Web เปิดได้ มากกว่า 12 รูปแบบ และรายการที่ถือเป็นทางการคือบทความเรื่องการนำเข้าและส่งออก ในศูนย์ช่วยเหลือ สรุปย่อ:

  • Microsoft Project — MPP, MPT, MPX, XML
  • Oracle Primavera P6 — XER, PMXML
  • GanttProject — GAN
  • ProjectLibre — POD
  • Asta Powerproject — PP
  • ConceptDraw — CDPX
  • FastTrack Schedule — FTS
  • GNOME Planner
  • Phoenix Project Manager — PPX
  • Synchro — SP
  • TurboProject — PEP
  • SDEF และ YAML ของ Ingantt เอง

คุณไม่จำเป็นต้องมีสิทธิ์ใช้งานของเครื่องมือที่สร้างไฟล์นั้น และไม่จำเป็นต้องติดตั้งเครื่องมือนั้นด้วย ไฟล์จะเปิดออกมาเป็นแผนภูมิแกนต์แบบโต้ตอบเต็มรูปแบบ — งานย่อย ความสัมพันธ์ระหว่างงาน การมอบหมายทรัพยากร หมุดหมาย เส้นฐาน และเส้นทางวิกฤต — และจากจุดนั้นแก้ไขได้ ไม่ใช่แค่อ่านได้

มันเขียนกลับออกมาเป็นอะไร

นี่คือครึ่งหนึ่งของคำถามที่ตัดสินว่าคุณใช้งานได้จริงหรือไม่

Ingantt บันทึกเป็น XML ที่เข้ากันได้กับ MS Project ดังนั้นแผนที่เปิดที่นี่สามารถกลับไปหาเพื่อนร่วมงานที่ยังใช้ Project ได้ จากเมนูไฟล์ — บนเว็บคือ ดาวน์โหลด — คุณยังส่งออกเป็น PDF, PNG, CSV, XML, YAML และ Markdown ได้ด้วย

เรื่องนี้สำคัญในช่วงเปลี่ยนผ่านที่กระท่อนกระแท่น เมื่อทีมครึ่งหนึ่งย้ายมาแล้วและอีกครึ่งยังไม่ย้าย คุณไม่ต้องขอให้ใครเปลี่ยนในวันเดียวกัน

คำถามเรื่องรูปแบบไฟล์ที่ควรถามก่อน

.mpp เป็นไฟล์ไบนารีแบบปิด เครื่องมือทุกตัวที่อ่านมันได้กำลังทำวิศวกรรมย้อนกลับรูปแบบของ Microsoft รวมถึง Ingantt ด้วย และความต่างจะปรากฏในแผนที่ซับซ้อน ขอให้เปิดไฟล์จริงของคุณ — ไม่ใช่ไฟล์ตัวอย่าง — แล้วตรวจสี่อย่างที่สำคัญกับคุณจริง ๆ คือ การเชื่อมโยงระหว่างงาน การมอบหมายทรัพยากร ปฏิทิน และวันสิ้นสุด ถ้าสี่อย่างนี้ข้ามมาได้ ที่เหลือคือรายละเอียด

ถ้าไฟล์ของคุณเป็น .mpp โดยเฉพาะ มีคำแนะนำทีละขั้นเรื่องการเปิดไฟล์ .MPP และถ้าคุณอยู่ในทีมที่แผนหายไปพร้อม Project Online หน้านั้นเป็นจุดเริ่มต้นที่มีประโยชน์กว่า
