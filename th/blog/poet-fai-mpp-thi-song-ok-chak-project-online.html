วิธีเปิดไฟล์ .MPP ที่ส่งออกจาก Project Online โดยไม่ใช้ Microsoft Project

วันยุติบริการ Project Online ที่ไมโครซอฟท์กำหนดไว้คือ 30 กันยายน 2026 เมื่อพ้นวันนั้น โครงการที่เก็บอยู่ในบริการจะเข้าถึงไม่ได้อีกต่อไป และไม่มีช่วงอ่านอย่างเดียวให้ด้วย สิ่งที่ส่งออกไว้ก่อนหน้านั้นคือสำเนาหลัก

ถ้าโครงการของคุณถูกบันทึกผ่าน Project บนเดสก์ท็อป สิ่งที่คุณมีตอนนี้คือโฟลเดอร์ที่เต็มไปด้วย ไฟล์ .MPP ซึ่งนำไปสู่คำถามที่มักตามมาในอีกไม่กี่วัน นั่นคือจะเปิดมันด้วยอะไร .MPP เป็นรูปแบบไบนารีเฉพาะของ Microsoft Project และสำหรับหลายทีม สิทธิ์ใช้งาน Project ก็หมดไปในจังหวะใกล้เคียงกับตัวบริการ

Ingantt เปิดไฟล์เหล่านี้ได้ในเบราว์เซอร์ อัปโหลดไฟล์หรือเลือกจาก Google ไดรฟ์ แล้วโครงการจะกลับมาเป็นแผนภูมิแกนต์แบบโต้ตอบที่สมบูรณ์ ทั้งงานย่อย ความสัมพันธ์ระหว่างงาน การกำหนดทรัพยากร หมุดหมายสำคัญ เส้นฐาน และเส้นทางวิกฤต ส่วนไฟล์ MS Project XML ที่วางอยู่ข้างไฟล์ส่งออกของคุณก็เปิดได้แบบเดียวกัน ไม่ต้องมีสิทธิ์ใช้งาน ไม่มีอะไรต้องติดตั้ง และทำงานเหมือนกันทั้งบน macOS, Linux หรือ Chromebook การเปิดไฟล์ .MPP ใช้เวลาราวสามสิบวินาที

อีกทั้งยังไม่ใช่แค่โปรแกรมดูไฟล์ แผนที่ส่งออกไว้สามารถวางแผนใหม่ได้ และส่งออกกลับเป็น MS Project XML ให้เพื่อนร่วมงานที่ยังใช้ Project อยู่

ขอบเขตก็ควรพูดกันตรงๆ Project Online เป็นแพลตฟอร์ม PPM ระดับองค์กร และ Ingantt ไม่ได้มาแทนการวิเคราะห์พอร์ตโฟลิโอ เวิร์กโฟลว์ด่านอนุมัติตามระยะ ใบบันทึกเวลา หรือรายงาน OData สิ่งที่มันมาแทนคือฝั่งการจัดตารางงาน นั่นคือตัวแผนเอง ถ้านั่นคือส่วนที่คุณต้องการให้ยังทำงานได้ในวันที่ 1 ตุลาคม อ่านรายละเอียดเพิ่มได้ที่ หน้าทางเลือกแทน Project Online
