สี่หน้าที่ของแผนโครงการ

แผนโครงการถูกถามสี่คำถามซ้ำแล้วซ้ำอีกตลอดอายุของโครงการ จะเสร็จเมื่อไร ใครทำอะไร จะใช้เงินเท่าไร เราอยู่ในกำหนดหรือไม่

แผนที่ตอบข้อหนึ่งได้ดีและอีกสามข้อต้องมานั่งตอบด้วยมือ ไม่ใช่แผน มันเป็นภาพถ่ายของแผน นี่คือความต่างระหว่างแผนภูมิแกนต์ที่วาดในสเปรดชีตกับเครื่องมือจัดกำหนดการ และคุ้มที่จะพูดให้ชัดว่าเครื่องมืออย่างหลังต้องทำอะไรได้

01 — วางแผนเวลา

งานนี้จะเสร็จจริง ๆ เมื่อไร

วันสิ้นสุดไม่ใช่สิ่งที่คุณเลือก มันหลุดออกมาจากความสัมพันธ์ระหว่างงานและระยะเวลาที่คุณกรอกไว้ และเลขคณิตที่คำนวณมันออกมาคือ วิธีเส้นทางวิกฤต เปลี่ยนระยะเวลาหนึ่งค่า วันทั้งหมดที่อยู่ถัดไปก็ขยับ — ขยับทันที ไม่ใช่รอให้ใครวาดแถบใหม่

สิ่งที่ต้องมีอยู่ข้างใต้: ความสัมพันธ์สี่ประเภท ข้อจำกัดแปดประเภท งานที่ถูกแบ่งและงานที่เกิดซ้ำ รูปแบบการกระจายงานเก้าแบบ ปฏิทินกำหนดเอง สัปดาห์ทำงาน และระยะเวลาแบบนับวันปฏิทิน เป็นกลไกที่ไม่หวือหวา แต่นี่คือกลไกที่แยกกำหนดการซึ่งอยู่รอดเมื่อเจอความจริง ออกจากกำหนดการที่ถูกทิ้งในสัปดาห์ที่สาม

02 — วางแผนทรัพยากร

ใครงานล้น ใครว่าง

ทุกงานกินเวลาของใครคนหนึ่ง แผนที่ไม่จำลองเรื่องนี้จะบอกคุณอย่างสบายใจว่าสามคนสามารถทำงานเต็มเวลาคนละสองงานในสัปดาห์เดียวกันได้

มอบหมายทรัพยากรประเภทแรงงาน วัสดุ ต้นทุน งบประมาณ และทรัพยากรทั่วไปให้กับงาน มุมมอง Resource Usage และ Team Planner ทำให้การจัดสรรเกินปรากฏขึ้นในวินาทีที่มันเกิด ไม่ใช่สัปดาห์ที่กำหนดส่งเลื่อน การปรับระดับอัตโนมัติแก้ความขัดแย้งตามลำดับความสำคัญ เวลาลอย หรือ ID — และแก้ภายในเวลาลอยที่มีอยู่เท่านั้นถ้าคุณสั่งไว้อย่างนั้น ตารางอัตรา A–E เก็บอัตราที่มีผลตามวันที่และความพร้อมใช้งานที่เปลี่ยนไปตามเวลา เพราะคนไม่ได้มีต้นทุนเท่ากันทั้งปีและไม่ได้ว่างทั้งปี

03 — วางแผนต้นทุน

จะใช้เงินเท่าไรจริง ๆ

คุณตั้งราคาชิ้นส่วนได้ แต่ตั้งราคาทั้งแผนยากกว่า เพราะค่าแรง ค่าล่วงเวลา วัสดุ และใบแจ้งหนี้ผู้ขาย ทั้งหมดแขวนอยู่บนกำหนดการที่ขยับอยู่ตลอด

ดังนั้นต้นทุนต้องรวมยอดขึ้นมาจากอัตราทรัพยากร ต้นทุนคงที่ และการใช้วัสดุ โดยต้นทุนคงที่ลงบัญชีตอนเริ่ม ตอนจบ หรือเฉลี่ยตามสัดส่วน — และต้องคำนวณใหม่ในจังหวะเดียวกับกำหนดการ คอลัมน์ earned value สิบสามคอลัมน์ (BCWS, BCWP, CPI, SPI, EAC, VAC, TCPI และอื่น ๆ) เปลี่ยนสิ่งนั้นเป็นตัวเลขสองตัวที่ผู้บริหารอ่านจริง ๆ คือ เราเร็วหรือช้ากว่ากำหนด และเราเกินหรือต่ำกว่างบประมาณ

04 — ติดตามความคืบหน้า

เราอยู่ในกำหนดหรือไม่

"อยู่ในกำหนด" มีความหมายก็เมื่อเทียบกับอะไรอย่างหนึ่ง สิ่งนั้นคือ เส้นฐาน — แผนอย่างที่เคยให้สัญญาไว้ เก็บไว้ข้าง ๆ แผนอย่างที่เป็นอยู่ตอนนี้

เส้นฐานสิบเอ็ดชุด (0–10) บวกแผนระหว่างกาลสิบชุด หมายความว่าคุณเก็บประวัติไว้ได้ ไม่ต้องเขียนทับทุกครั้งที่แผนได้รับอนุมัติใหม่ คอลัมน์เส้นฐานห้าสิบห้าคอลัมน์และคอลัมน์ส่วนต่างห้าคอลัมน์ให้การเปรียบเทียบ แถบเส้นฐานวางทับบนแผนภูมิแกนต์ ทำให้เห็นได้โดยไม่ต้องอ่านตาราง Update Project และ Reschedule Uncompleted Work เลื่อนทุกอย่างที่ยังไม่เกิดขึ้นถึงวันสถานะ ด้วยการกระทำครั้งเดียวแทนที่จะเป็นสองร้อยครั้ง

ส่วนที่ผูกทั้งสี่เข้าด้วยกัน

สี่หน้าที่นี้ไม่ใช่เครื่องมือสี่ชิ้น เหตุที่ทั้งสี่อยู่ในไฟล์เดียวกันคือ ทุกคำตอบเปลี่ยนอีกสามคำตอบ งานที่เลื่อนหนึ่งงานเลื่อนวันสิ้นสุด วันสิ้นสุดเลื่อนว่าใครยุ่งในเดือนพฤศจิกายน นั่นเลื่อนต้นทุน และต้นทุนเลื่อนส่วนต่างที่คุณรายงาน

Ingantt ทำทั้งสี่อย่างในเบราว์เซอร์ ในระดับความลึกเดียวกับที่ Microsoft Project ทำ — บวก AI สำหรับร่างและแก้แผน Google Drive สำหรับแชร์ และไฟล์ MS Project กับ Primavera เข้าและออก ไม่มีการสมัครใช้ AI แยก และไม่ต้องสร้างบัญชีใหม่

ถ้าคุณย้ายมาจาก MS Project หรือ Primavera พร้อมไฟล์ในมือ เริ่มด้วยการเปิดไฟล์หนึ่งไฟล์ แล้วดูว่าคำตอบทั้งสี่กลับมาครบถ้วนหรือไม่
