ब्राउज़र में कौन-कौन सी प्रोजेक्ट फ़ाइलें खुलती हैं? पूरी सूची

ज़्यादातर लोग Ingantt तक तब पहुँचते हैं जब उनके हाथ में कोई फ़ाइल होती है। कभी Microsoft Project की .mpp। और अक्सर Primavera P6 की .xer, GanttProject की .gan, या कोई ऐसी फ़ाइल जो किसी ठेकेदार ने भेजी है और जिसे खोलने का सॉफ़्टवेयर अब टीम में किसी के पास नहीं है।

तो यहाँ सीधी सूची है, बिना किसी मार्केटिंग के।

Ingantt for Web क्या खोलता है

Ingantt for Web 12 से ज़्यादा फ़ॉर्मैट खोलता है, और प्रामाणिक सूची हेल्प सेंटर का इम्पोर्ट और एक्सपोर्ट लेख है। संक्षेप में:

  • Microsoft Project — MPP, MPT, MPX, XML
  • Oracle Primavera P6 — XER, PMXML
  • GanttProject — GAN
  • ProjectLibre — POD
  • Asta Powerproject — PP
  • ConceptDraw — CDPX
  • FastTrack Schedule — FTS
  • GNOME Planner
  • Phoenix Project Manager — PPX
  • Synchro — SP
  • TurboProject — PEP
  • SDEF, और Ingantt का अपना YAML

जिस टूल से फ़ाइल आई है, उसका लाइसेंस आपको नहीं चाहिए। वह टूल इंस्टॉल होना भी ज़रूरी नहीं। फ़ाइल एक पूरी इंटरैक्टिव गैंट चार्ट के रूप में खुलती है — सब-टास्क, डिपेंडेंसी, संसाधन असाइनमेंट, माइलस्टोन, बेसलाइन और क्रिटिकल पाथ — और उसके बाद वह केवल पढ़ने योग्य नहीं, संपादन योग्य होती है।

यह वापस क्या लिखता है

सवाल का यही आधा हिस्सा तय करता है कि आप इसे असल में इस्तेमाल कर पाएँगे या नहीं।

Ingantt MS Project-संगत XML में सहेजता है, इसलिए यहाँ खोला गया प्लान उस सहकर्मी के पास वापस जा सकता है जो अब भी Project चला रहा है। फ़ाइल मेन्यू से — वेब पर डाउनलोड — आप PDF, PNG, CSV, XML, YAML और Markdown में भी एक्सपोर्ट कर सकते हैं।

माइग्रेशन के उस असहज दौर में यही काम आता है, जब आधी टीम आ चुकी होती है और आधी नहीं। आप किसी से यह नहीं कह रहे कि उसी दिन बदल जाओ।

फ़ॉर्मैट पर सबसे पहले पूछने लायक सवाल

.mpp एक प्रोप्राइटरी बाइनरी फ़ॉर्मैट है। जो भी टूल इसे पढ़ता है, वह Microsoft के फ़ॉर्मैट की रिवर्स इंजीनियरिंग कर रहा है — Ingantt भी — और अंतर जटिल प्लान में ही सामने आते हैं। नमूना नहीं, अपनी असली फ़ाइल खोलिए और वे चार चीज़ें देखिए जो आपके लिए सचमुच मायने रखती हैं: डिपेंडेंसी लिंक, संसाधन असाइनमेंट, कैलेंडर और समाप्ति तिथि। ये आ गईं, तो बाक़ी ब्यौरा है।

अगर आपकी फ़ाइल ठीक .mpp है, तो .MPP फ़ाइल खोलने का चरण-दर-चरण तरीका मौजूद है। और अगर आप उन टीमों में हैं जिनके प्लान Project Online के साथ चले गए, तो वह पेज शुरुआत के लिए ज़्यादा उपयोगी है।
