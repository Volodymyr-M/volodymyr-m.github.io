Project Online이 사라집니다 — 내보낸 .MPP 파일 여는 방법

Microsoft가 정한 Project Online 종료일은 2026년 9월 30일입니다. 그 이후에는 서비스에 보관된 프로젝트에 더 이상 접근할 수 없고 읽기 전용 기간도 없습니다. 미리 내보낸 파일이 원본 사본이 됩니다.

데스크톱 Project로 프로젝트를 저장해 왔다면 지금 남은 것은 .MPP 파일이 담긴 폴더입니다. 그리고 며칠 지나면 어김없이 떠오르는 질문이 있습니다. 이걸 무엇으로 여느냐는 것이죠. .MPP는 Microsoft Project의 독자적인 이진 형식이고, 많은 팀에서 Project 라이선스도 서비스와 비슷한 시기에 함께 사라졌습니다.

Ingantt는 이 파일을 브라우저에서 엽니다. 파일을 업로드하거나 Google 드라이브에서 고르면 프로젝트가 완전한 대화형 간트 차트로 돌아옵니다. 하위 작업, 종속성, 리소스 할당, 마일스톤, 기준선, 주 공정까지 그대로입니다. 내보내기 파일 옆에 있는 MS Project XML도 같은 방식으로 열립니다. 라이선스도 필요 없고 설치할 것도 없으며 macOS, Linux, Chromebook에서 똑같이 동작합니다. .MPP 파일 열기에 걸리는 시간은 30초 남짓입니다.

단순한 뷰어도 아닙니다. 내보낸 계획은 다시 세울 수 있고, 여전히 Project를 쓰는 동료를 위해 MS Project XML로 되돌려 보낼 수도 있습니다.

한계는 분명히 말씀드리는 편이 낫겠습니다. Project Online은 엔터프라이즈 PPM 플랫폼이었고, Ingantt는 포트폴리오 분석이나 단계 승인 워크플로, 작업 시간표, OData 보고를 대체하지 않습니다. 대체하는 것은 일정 관리 쪽, 즉 계획 그 자체입니다. 10월 1일에 계속 돌아가야 하는 부분이 바로 그것이라면 Project Online 대안 페이지에 더 자세히 정리해 두었습니다.
